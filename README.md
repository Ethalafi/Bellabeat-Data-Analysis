# Bellabeat Case Study: How Can a Wellness Company Play It Smart?

*Analyzing Fitbit activity and sleep data using Python to identify potential marketing opportunities for Bellabeat.*

## Project Overview

This case study explores Fitbit activity and sleep data to better understand consumer wellness habits. The goal is to identify patterns that could help Bellabeat develop marketing strategies for its Leaf wellness tracker.

Using Python, pandas, Matplotlib, and Jupyter Notebook, I analyzed daily activity levels, sleep duration, and consistency in user behavior to develop three data-driven marketing recommendations.
